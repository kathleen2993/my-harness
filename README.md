# my-harness: 의뢰서 CG 제작 하네스

Word 의뢰서 한 건을 넣으면 AI가 슬라이드를 정리하고, Figma 템플릿 컴포넌트로 의뢰 CG 묶음을 만드는 하네스입니다.
허들링 클럽 1차 실험(트랙 B: 도메인 스토리텔링) 제출물입니다.

> 공개용 버전입니다. Figma 컴포넌트·레이어 이름은 일반 이름으로 바꿨습니다.

## 파일

| 파일 | 내용 |
|---|---|
| [story-service.md](story-service.md) | 서비스 스토리 (R0-A). 주어 = 서비스 사용자. 게이트의 **합격선** |
| [story-work.md](story-work.md) | 작업 스토리 (R0-B). 주어 = 나(디자이너). 게이트의 **위치**와 에이전트의 **경계** |
| [PRD.md](PRD.md) | 제품 요구사항. 실제 의뢰서 28건을 분석해 슬라이드 타입을 4개에서 7개로 늘림 |
| [design.md](design.md) | Figma 작업 디자인 규칙 (SSOT) |

## 핵심 내용

- **어기면 안 되는 것**: 가격·할인율은 의뢰서 원문과 100% 일치, 템플릿 컴포넌트 detach 0개
- **멈칫 지점 (게이트 위치)**: ③ 타입 정하기, ⑥ 가격 대조
- **사람 승인**: ⑥ → ⑦ 사이 한 곳
- **발견**: 의뢰서 28건 중 기존 4개 타입에 맞지 않는 슬라이드가 반복됨 → 빈 전면(7건), 다상품형(약 8건), 사은품·이벤트형(약 9건)을 추가 예정
