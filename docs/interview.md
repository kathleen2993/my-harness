## R3. 파이프라인 (확정 2026-10-11)

### 4단계

| 단계 | 담당 | 입력 | 출력 |
|---|---|---|---|
| p1 의뢰서 분석 | 🤖 Claude | Word 의뢰서 (.docx) | 슬라이드 목록 (메타데이터 분리, 슬라이드별 원문) |
| p2 기획 | 🤖 Claude | 슬라이드 목록 | 슬라이드 기획 (타입·배치·토글·글자값) + 🚦 게이트1 |
| p3 Figma 생성 | 🤖 Claude → 🔌 플러그인 → 👤 디자이너 | 슬라이드 기획 | Claude가 구조(전면 배치·카드 종류·토글)를 만들고, **기존 플러그인**이 글자를 넣고, **디자이너가 이미지**를 직접 찾아 넣는다 |
| p4 검수 | 🤖 Claude (읽기 전용) | Figma 실제 상태 + 의뢰서 원문 | 검수 결과 + 🚦 게이트2 → 👤 디자이너 승인 (사람 승인 1곳) |

- 전달(PD/MD에게 보내기)은 하네스 밖. 디자이너가 직접.
- 파일명은 R4에서 확정.

### 결정 이유

- **글자 = 기존 플러그인**: Figma MCP는 Figma 서버에서 실행되어 Pretendard(로컬 설치 폰트)를 쓸 수 없다. 플러그인은 디자이너 컴퓨터의 Figma 앱 안에서 돌아 로컬 폰트를 쓴다. 제출 우선이므로 플러그인은 새로 만들지 않고 **기존 플러그인을 그대로** 쓰고, 하네스가 그 플러그인의 데이터 형식으로 결과를 만든다.
- **이미지 = 사람**: 소스를 찾아 골라 넣어야 하는 작업이고, Figma MCP는 이미지 파일 넣기를 지원하지 않는다.
- 회사 공유 폰트(회사 조직)는 이 파일에서 Pretendard가 조회되지 않음 → 추후 관리자 확인 시 Claude가 글자까지 넣는 방식으로 전환 가능.

### 되돌아가는 길

| 실패 | 돌아갈 곳 |
|---|---|
| 게이트1 실패 (타입·필수 칸 누락) | p2 |
| "판단 필요" 남음 | 디자이너에게 질문 → p2 |
| 게이트2 가격 불일치·더미 글자 | p3 (플러그인 재실행) |
| 게이트2 타입·구조 오류 | p2 |
| 승인 반려 | 사유에 따라 p2 또는 p3 |
| 같은 게이트 3번 실패 | 멈추고 디자이너 호출 |

### 시연

- 공개 저장소이므로 실제 의뢰서 대신 **가상 의뢰서** `samples/sample_request.docx`(가상 브랜드 "예시뷰티")로 시연한다.
- 구성: 1 혜택(체크리스트) / 2·3 상품형 / 4 다상품 2단 / 5 사은품 / 6 스토리 / 슬림배너 2개 / 빈 전면 1장
- 시연 파일: 화면 녹화 + Figma 결과 스크린샷 + 실행 기록 파일

## R5. 게이트 (확정 2026-10-11)

이미 정해진 것: 통과 조건 = `rules.yaml` / 사람 승인 = p4 후 `approval.md` 1곳 / 복귀·한도 = R3 / ★서비스 조건 = 가격 불일치 0, 카드 detach 0

### Q1. 가격 일치 세는 법 (확정)

1. Figma의 모든 가격·할인율 글자는 의뢰서 원문에 **같은 문자열**로 있어야 한다 (`35,400`, `40%`)
2. 하네스가 계산한 숫자 금지 (체감가·할인율 직접 계산 X, 원문 그대로만)
3. 쉼표는 원문 그대로, "원"은 `#WON_txt`가 처리하므로 숫자 칸에는 숫자만, "방송중10%" 같은 붙은 표기는 보존
4. 양방향: Figma에 있는데 원문에 없으면 불일치, 원문에 있는데 Figma에 없으면 누락 → 둘 다 실패. "판단 필요"로 넘긴 슬라이드는 제외

### Q2. 나머지 Figma 검사 세는 법 (확정)

| 항목 | 세는 법 |
|---|---|
| 더미 글자 | 보이는 글자 중 `#`으로 시작하거나 레이어 이름과 내용이 같은 것. 숨김 레이어 제외 |
| 카드 detach | 각 전면 안의 카드가 인스턴스이고 원본이 v2 템플릿 컴포넌트인지. 바깥 375×667 프레임 제외 |
| 폰트 대체 | 결과 글자의 폰트가 템플릿 원본 레이어 폰트와 다르면 1개 |
| 장수·순서 | 전면 개수 = `p2_plan.json` 슬라이드 수, 이름 `01_`, `02_`… 순서 |
| 슬림배너·빈 전면 | 요청이 있으면 `슬림배너_묶음` / 카드 없는 전면이 있어야 함 |

- 판정: Claude 판정 에이전트가 Figma를 **읽기만** 해서 `p3_figma-export.json` 작성 → `verify.mjs`가 원문·`rules.yaml`과 비교해 통과/실패 결정
